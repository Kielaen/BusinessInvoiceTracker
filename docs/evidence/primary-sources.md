## Registry evidence

Critical runtime images use exact tags and immutable manifest-list digests in the
Compose file and Dockerfiles. The digests were obtained from Docker Hub or
Microsoft Container Registry v2 manifests on 2026-07-30. This pins PostgreSQL
17.10, Redis 7.4.10, Dapr 1.17.7 components, Mailpit 1.30.6, Aspire dashboard
13.4.2, .NET SDK 10.0.302, ASP.NET runtime 10.0.10, Node 24.14.1, and nginx
1.31.3 on Alpine 3.24. The nginx pin was refreshed on 2026-08-04 after the
older 1.29.5/Alpine 3.23 final image produced critical/high scanner findings;
the replacement final base scanned clean at those severities. Clean image build
remains an executable gate rather than a registry-only claim.
